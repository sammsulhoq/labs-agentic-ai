# Codebasics — Agentic AI with LangChain

Follow-along implementations and notes for the [Codebasics Agentic AI crash course](https://www.youtube.com/watch?v=D74el9mvNak).

## Scope

The course description covers generative AI and agentic AI fundamentals, practical LangChain programming, and two guided applications: a shopping agent and a telecom RAG chatbot. Technologies mentioned include ChromaDB, Streamlit, SQLite, Hugging Face, sentence transformers, and multiple LLM providers.

## Folder layout

```text
codebasics-agentic-ai-langchain/
├── README.md
├── fundamentals/         # Introductory exercises as implemented
├── shopping-agent/       # Guided shopping-agent application
└── telecom-rag-chatbot/  # Guided retrieval-augmented chatbot
```

Create each directory when you begin its corresponding exercise. Keep application-specific requirements, configuration examples, and run instructions inside that application's folder.
